# Franciszek Stefaniuk | Portfolio

Selected AI, automation and software projects: private document search, document processing, and MarketSim.

## Website

A static HTML, CSS and JavaScript site. Open `index.html` or serve this directory with any static web server. No build step or backend is required.

For GitHub Pages, publish the `main` branch from the repository root.

## Projects

Commercial projects are described at a high level and anonymised. This repository contains no commercial source code or client data.

The interactive MarketSim demo uses my public [MarketSim project](https://github.com/theFishy-1/MarketSim), with portfolio navigation, accessibility labels and responsive layout adjustments. Simulation logic is unchanged. The preview chart comes from a reproducible simulation run and is labelled as simulated data.

## Dependencies

The website loads Google Fonts. The demo loads Chart.js from jsDelivr; its other charts use native canvas.
